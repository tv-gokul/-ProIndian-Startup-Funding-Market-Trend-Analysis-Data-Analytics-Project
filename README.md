# -ProIndian-Startup-Funding-Market-Trend-Analysis-Data-Analytics-Project

Indian startup funding datasets (10,000+ records) to study sector-wise, city-wise, and year-wise investment trends.
Performed data cleaning and preprocessing using Pandas to handle missing values, inconsistent categories, and incorrect funding entries.
Conducted exploratory data analysis (EDA) to identify high-growth sectors, funding distribution patterns, and geographic startup hubs.
Developed data visualizations using Matplotlib and Seaborn to present funding trends and industry comparisons.
Built an interactive Streamlit dashboard to filter startup data by industry, city, and funding year.
Generated business and VC-style insights on emerging sectors, declining industries, and regional funding disparities
